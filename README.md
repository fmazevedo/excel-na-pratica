   - pdf/roteiro-aula1.pdf

   - pdf/roteiro-aula3.pdf
3. Coloque as bases Excel na raiz com os nomes usados nas páginas.
4. Envie toda a pasta para um repositório GitHub e ative GitHub Pages.
